How a round moves through AdAutonomy

1 · MatchEach frame to its UAID row in the tracker
2 · Data checksNames, sizes, formats, counts, status
3 · Visual checksLogo, CTA, talent, edges, strays
4 · Studio listChanges needed, please check, passed

Data checks run instantly from the files alone. Visual checks run only when you ask, and the order of precedence is always the tracker row, then the platform rule, then the brand rule.

              What this beta can and cannot do yet

              • Takes the order from Excel, CSV, a Google Sheets link (with a tab name) or an Airtable table link, and frames from exports or a Google Drive folder link. One box, any source.
              • Reads exports and the tracker from the files alone; no board access needed.
              • Data checks, the four-section studio list, saved reports, editable rules, workflow mapping.
              Needs the workspace connections
              • Visual checks and the reviewer panel. They work from the link John sent you; there is nothing to enter.
              • Private Google Sheets and Drive folders need the workspace Google account; link-shared ones work without it.
